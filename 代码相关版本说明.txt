================================================================================
一、版本概述
================================================================================

本版本在 openGauss 6.0.0 基础上合入以下能力，面向三节点 WAN TPCC
多主（Epoch Multimaster）实验环境：

  1. OCC 磁盘表事务引擎（src/occ/）
     - 乐观并发控制（OCC）读写路径、Sentinel 锁、CSN 管理、OpFusion 接入
     - Delta Table / 写集 / 统计与 pre-abort 优化

  2. Epoch 多主复制模块（src/epoch/）
     - 物理/逻辑 Epoch 推进、ZMQ 网络收发、CRDT 合并、异步提交流水线
     - TPCC 基准脚本（scripts/epoch_benchmark/）

  3. occ-opt 版本暂存与延迟写回（src/occ-opt/，设计文档 §GeoGauss 磁盘表）
     - 分片哈希暂存表 O_StagingTable、脏页追踪、后台刷脏、heap 写回回调
     - 通过 occ_staging_bridge 接入 OCC 读写/校验路径

  4. dynamic-net 异构网络复制协议（src/dynamic-net/，设计文档 §异构网络）
     - FIXED / CATCHUP Epoch 推进、Proxy Merge、慢节点 PartialSnapshot
     - 流量整形（Up/Down/Bi Limit）、消息分发与 CRDT 合并框架
     - 通过 e_dyn_net / e_dyn_net_bridge 接入 Epoch 网络层

设计原则：
  - 新模块始终编译链接进 gaussdb，**默认运行时关闭**，行为与 6.0.0 一致
  - 开关通过 postgresql.conf GUC 控制，由 scripts/epoch_benchmark/configure_node.sh 统一写入

五、运行时 GUC 参数（新增/相关）
================================================================================

【Epoch 多主】
  enable_epoch_multimaster       多主总开关
  epoch_node_id / epoch_total_nodes / epoch_peer_hosts
  epoch_physical_interval_ms     物理 Epoch 间隔（ms）
  epoch_phys_logical_gap_limit   物理-逻辑 Epoch 差距上限
  epoch_commit_sync              同步/异步提交模式
  epoch_async_*                  异步模式调优参数

【dynamic-net 异构网络】（默认均为 off/false）
  enable_epoch_dyn_net           异构网络总开关
  epoch_dyn_net_catchup          CATCHUP 模式（否则 FIXED）
  epoch_dyn_net_proxy            Proxy Merge 路径
  epoch_dyn_net_slow_nodes       慢节点 ID 列表
  epoch_dyn_net_lag_tolerance    lag 跳变阈值
  epoch_dyn_net_queue_tolerance  队列跳变阈值
  epoch_dyn_net_catchup_k        CATCHUP 跳跃系数
  epoch_dyn_net_rtt_ms           RTT 补偿（ms）
  epoch_dyn_net_upload_bps       上行带宽限制（bytes/s，0=不限）
  epoch_dyn_net_download_bps     下行带宽限制
  epoch_dyn_net_bw_mode          带宽模式枚举

【OCC / occ-opt】
  enable_occ_disk                OCC 磁盘表（默认 on，与多主联动）
  enable_occ_staging             版本暂存哈希表
  occ_enable_stats_log           OCC 统计日志

修改 GUC 后需 restart 数据库实例。

七、模块接入关系（运行时）
================================================================================

  客户端 SQL
      ↓
  OpFusion / Executor ──→ OCC (o_access / o_txn_access / o_occManager)
      │                        ↓ 
      │                   occ-opt (O_StagingTable 读写/flush)
      ↓
  xact.cpp ──→ Epoch (e_xact / e_pipeline / e_statistician)
      │            ↓ 
      │       dynamic-net (DnEpochManager / DnTransport / DnProxyMerge)
      ↓
  postmaster ──→ epoch_worker (e_worker_main 物理定时器 + ZMQ 收发)
